## 🙋 关于我

深圳城市职业学院 25 级「智能·创造者创新实验班」在读。习惯用项目驱动学习：先立一个真实需求，再把技术栈一层层补上。

目前主要在做三件事：

- **AI Agent** —— 把大模型接进真实工作流，而不是停在对话框里（记忆转码、对话式助手、情感分析这类「AI 要落地」的题目）。
- **桌面工具** —— 面向不懂命令行的普通用户，把复杂流程收进一个可视化应用。
- **DSH 插件生态** —— 给自己每天用的工具写插件，攒成一套可复用、可分发的插件集合。
